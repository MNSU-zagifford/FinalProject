# MNSU CampusEco

## Smart Campus Logistics System

MNSU CampusEco is a full-stack web application project designed to support sustainable package delivery operations at Minnesota State University, Mankato.

The system coordinates package movement from a centralized campus logistics hub to residence halls, academic buildings, administrative offices, and other campus destinations using low-emission electric vehicles and student delivery crews.

## User Modules

### Central Hub Personnel
Central Hub personnel can register incoming packages, enter tracking information, select package size and weight, assign destinations, and identify priority shipments.

### Eco-Transit Crew
Student delivery workers can view assigned delivery routes, package information, vehicle assignments, and electric vehicle battery information.

### Students, Faculty, and Staff
Campus recipients can track packages, view delivery status, select delivery preferences, receive notification options, and view environmental impact information.

## Phase 1

Phase 1 focuses on the frontend foundation and static user interface.

Technologies:

- HTML5
- CSS3
- CSS Grid
- Flexbox
- HTML5 Form Validation

No backend database or dynamic data processing is implemented during Phase 1.
