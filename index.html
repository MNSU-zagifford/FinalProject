🏛️ System Architecture & Full-Stack Platform Tiers

4-Tier Multi-Stack Engine

CampusEco implements a robust multi-tier architecture separating user interface, asynchronous telemetry streaming, secure server endpoints, and relational persistence.

Tier 1 • Client Layer Two-Way Binding

🅰️ AngularJS & UI

AngularJS 1.8.2 reactive controllers, live courier broadcast dispatch, and responsive CSS Grid/Flexbox in MNSU Purple & Gold.

Tier 2 • REST Microservice HTTP / Port 3000

🟢 Node.js Server

Zero-dependency asynchronous server built with core HTTP modules. Streams synchronized JSON state and real-time vehicle GPS telemetry.

Tier 3 • Backend Engine PHP PDO / Security

🐘 PHP Service Layer

RESTful package and fleet endpoints. Enforces SQL injection prevention via PDO prepared statements and structured JSON outputs.

Tier 4 • Relational DB MySQL / MariaDB

🗄️ Relational Database

Persistent normalized relational schema containing structured packages, electric vehicles, and delivery audit event tables.
