🏛️ System Architecture (Full-Stack Multi-Tier Separation)

Rubric Ready: 4 Components Verified

CampusEco implements a robust multi-tier architecture separating presentation, microservice telemetry, secure data access, and relational persistence.

Tier 1 • Client Two-Way Data Binding

🅰️ AngularJS & UI

AngularJS 1.8.2 reactive controllers, ng-model two-way data binding, dynamic character budgeting, and responsive CSS Grid/Flexbox in MNSU Purple & Gold.

Tier 2 • REST Server HTTP / Port 3000

🟢 Node.js API

Zero-dependency asynchronous server built with core http, fs, and path modules. Streams synchronized JSON state and real-time GPS telemetry.

Tier 3 • Backend Server PHP PDO / Security

🐘 PHP Engine

Parameterized RESTful endpoints (api/packages.php, api/vehicles.php). Enforces SQL injection prevention via PDO prepared statements and structured JSON responses.

Tier 4 • Database MySQL / MariaDB

🗄️ Relational DB

Persistent normalized relational schema (mnsu_campuseco) containing structured packages, vehicles, and audit logs with ENUM constraints.

Source: api/packages.php — Parameterized prepared statement preventing SQL injection attacks: 

// 1. Secure Database Connection via PDO
$pdo = new PDO("mysql:host=127.0.0.1;dbname=mnsu_campuseco;charset=utf8mb4", $user, $pass, [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES => false
]);

// 2. Parameterized Prepared Insert (SQL Injection Protected)
$stmt = $pdo->prepare('INSERT INTO packages (tracking_number, destination, size, weight, priority, status) 
                       VALUES (:tracking, :dest, :size, :weight, :priority, "Received")');
$stmt->execute([
    ':tracking' => strtoupper(trim($data['tracking'])),
    ':dest'     => trim($data['destination']),
    ':size'     => $data['size'] ?? 'Medium',
    ':weight'   => $data['weight'] ?? 1.0,
    ':priority' => $data['priority'] ?? 'Normal'
]);

// 3. Status Update via PUT
$stmt = $pdo->prepare('UPDATE packages SET status = :status WHERE tracking_number = :tracking');
$stmt->execute([':status' => $data['status'], ':tracking' => strtoupper(trim($data['tracking']))]);

Source: database/schema.sql — Normalized relational tables for electric fleet and package logistics: 

CREATE DATABASE IF NOT EXISTS `mnsu_campuseco`;
USE `mnsu_campuseco`;

-- 1. Table for Electric Delivery Fleet
CREATE TABLE `vehicles` (
    `id` INT AUTO_INCREMENT PRIMARY KEY,
    `cart_code` VARCHAR(20) NOT NULL UNIQUE,
    `name` VARCHAR(50) NOT NULL,
    `battery_level` INT NOT NULL DEFAULT 100,
    `status` ENUM('Available', 'On Delivery', 'Charging', 'Maintenance') DEFAULT 'Available'
);

-- 2. Table for Campus Packages
CREATE TABLE `packages` (
    `id` INT AUTO_INCREMENT PRIMARY KEY,
    `tracking_number` VARCHAR(30) NOT NULL UNIQUE,
    `destination` VARCHAR(120) NOT NULL,
    `size` ENUM('Small', 'Medium', 'Large') DEFAULT 'Medium',
    `weight` DECIMAL(5,2) DEFAULT 1.00,
    `priority` ENUM('Normal', 'Urgent') DEFAULT 'Normal',
    `status` ENUM('Received', 'Loaded', 'En Route', 'Delivered') DEFAULT 'Received',
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Source: live-dispatch.js — AngularJS two-way model binding driving live courier updates: 

angular.module("campusEcoLive", [])
  .controller("LiveController", ["$scope", function ($scope) {
    // Two-way bound model variables
    $scope.note = "EcoCart 04 en route to Centennial Student Union with priority packages.";
    $scope.view = "active";
    $scope.maxChars = 120;

    // Live character counter calculated dynamically
    $scope.charsLeft = function () {
      return $scope.maxChars - ($scope.note ? $scope.note.length : 0);
    };

    // Quick courier dispatch presets
    $scope.presets = [
      "EcoCart 04 arriving at Centennial Student Union (Suite 173).",
      "Julia Sears & Preska Hall deliveries completed.",
      "Advisory: Electric carts operating on primary pedestrian corridors."
    ];
    $scope.applyPreset = function (p) { $scope.note = p; };
    $scope.clearNote = function () { $scope.note = ""; };
  }]);
